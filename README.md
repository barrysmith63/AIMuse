# AIMuse™

## The Open-Source AI-Powered Successor to Adobe Muse

AIMuse is a layer-first, AI-assisted visual website builder designed to provide the freedom of Adobe Muse while embracing modern AI, GitHub Copilot, and responsive web technologies.

Design websites visually.

Generate pages with AI.

Modify projects with Copilot.

Export clean HTML, CSS, and JavaScript.

Publish directly to GitHub Pages.

# Key Differentiator

Unlike Wix, Squarespace, Elementor, and WordPress page builders, AIMuse uses a Layer-First architecture inspired by:

- Adobe Muse
- Photoshop
- Illustrator
- Figma

Users organize websites using logical layers instead of rigid blocks.
